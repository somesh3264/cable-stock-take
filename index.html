    Checking the Tally connection…

    Set up the Tally connector on the PC where TallyPrime runs:

    1. In TallyPrime, open F1 (Help) → Settings → Connectivity → Client/Server configuration. Set TallyPrime is acting as to Both and Port to 9000, then restart Tally. Keep your company open.
    2. Install Node.js LTS from nodejs.org on that PC.
    3. Unzip the connector folder you received, then double-click start-connector.bat. Run install-autostart.bat once to start it with Windows.

    Once it checks in, this panel turns green and book stock appears below.
